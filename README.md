# Rockland

**Rockland** is a mobile application designed to help users explore, identify, and learn about rocks through an interactive and structured learning experience. The platform combines rock information, identification, collections, missions, and achievements with an administrative web application for managing platform data and user activities.

> **University Final Year Project · Collaborative Development**

---

## Overview

Rockland was developed as a collaborative software project focused on creating an engaging educational platform for rock exploration and learning.

The system consists of a **mobile application** for general users and an **administrative web application** for managing platform content and user-related data.

The project combines mobile development, UI/UX design, system modelling, cloud-based data management, and administrative tools into a single platform.

---

## Key Features

### Mobile Application

* Explore and learn about different types of rocks
* Access structured rock information and educational content
* Identify and collect rocks within the application
* Track user progress and activities
* Complete missions and achievements
* Gamification features to encourage continued learning
* User profile and collection management

### Administrative Web Application

* Manage rock and platform information
* Monitor user-related activities
* View and update application records
* Manage data stored within Firebase
* Provide administrators with a centralized interface for platform management
